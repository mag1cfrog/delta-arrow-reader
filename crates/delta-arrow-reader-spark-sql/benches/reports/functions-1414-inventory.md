# Spark-only function row work (#1414)

This inventory covers the 113 measured Spark-only cases outside the
window group assigned to #1408. It traces the frozen SQL shapes through
the registrations and execution loops at staging commit
`6f78dfe026db66a62db23a3dcb1fae802fd7d380`. The two ANSI timing columns
come from the [original #1391 results](functions-1391-results.csv), in
median ns per input row above a plain projection. The table is ranked
by the larger ANSI median.

The existing CSV, JSON, XML and numeric parsers generally prepare their
literal schema or format once. Some still build an array containing one
copy per row before reading the first value. The source review also
found repeated literal materialization or setup in datetime, URL,
number rounding, map and encryption paths. The entries below identify
the repeated operation and the source. The two TRY_AES measurements
precede the runtime change in #1405.
